Fichier tmux.conf : préfixe backtick, souris, palette Catppuccin Mocha appliquée à la main (mode, messages, menus, bordures, status bar), fenêtres inactives masquées, extended-keys pour Shift+Entrée. Il branche la détection d'état : status-right appelle cc-states.sh via #( ) toutes les 5 s, prefix + w et prefix + s lancent cc-states.sh puis un choose-tree coloré selon l'option @cc_state, prefix + a lance cc-jump.sh. L'onglet courant affiche @cc_perimeter_ok quand il est posé.
