Vue d'ensemble de tmux-claude-theme : une configuration tmux sous palette Catppuccin Mocha, enrichie d'une détection visuelle de l'état des sessions Claude Code (waiting, work, idle, shell) et de l'affichage du périmètre intersession. Le projet est entièrement en Bash, sans dépendance applicative : un fichier tmux.conf, deux scripts d'état appelés par tmux, un hook Claude Code, deux scripts d'installation et un harnais de tests sur fixtures.
